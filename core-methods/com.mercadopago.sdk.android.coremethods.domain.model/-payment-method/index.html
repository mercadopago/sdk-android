Represents a payment method with various details related to financial transactions.

Parameters

financialInstitution

A list of financial institutions associated with the payment method.

payerCost

A list of costs associated with the payer for this payment method.

issuer

The issuer of the payment method, which may be an entity or financial institution.

totalFinancialCost

The total cost incurred for using the payment method, as a string.

minAccreditationDays

The minimum number of days required for accreditation, as a string.

maxAccreditationDays

The maximum number of days required for accreditation, as a string.

merchantAccountId

An identifier for the merchant account associated with this payment method, as a string.

id

A unique identifier for this payment method.

paymentTypeId

The type of payment associated with this method.

accreditationTime

The time required for accreditation, as a string.

card

The card details associated with the payment method, if applicable.

thumbnail

A thumbnail image URL representing the payment method.

bins

A list of bank identification numbers (BINs) associated with this payment method.

marketplace

An identifier for the marketplace this payment method is available in.

deferredCapture

Indicates if the capture of money is deferred.

agreements

A list of agreements applicable to this payment method.

labels

A list of labels that provide additional information about the payment method.

siteId

The identifier for the site in which this payment method is used.

processingMode

The mode of processing for the payment.

additionalInfoNeeded

A list of additional information required for processing this payment method.

status

The current status of the payment method.
